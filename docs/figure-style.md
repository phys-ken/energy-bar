# 場面の図の描き方（リードα物理基礎・物理を見て決めた。2026-11-16）

先生の指摘「図のクオリティが低すぎる。全数調査して。リードαとかちゃんと見て予習してから」を受けて、
リードα（Drive の出版社データ、読むだけ）の 14〜90 ページの図を見て書き出した。

## リードαの図の特徴

| 項目 | リードαの描き方 |
|---|---|
| 大きさ | 図は必要なものだけを、余白なく詰めて描く（幅 35〜60 mm ほど）。物体は図に対して大きい |
| 場所の名前 | 点に A・B・C・O・P などの記号を添える（物体の横、または床の線の下）。場面の説明は文で書く |
| ばね | コイル（輪が連なる形）。ギザギザではない |
| 動き | 物体の動く道すじを点線で描き、先に矢じり（鉛直投げ上げは上がって下がる点線） |
| 速さ | 物体から細めの矢印、そばに「19.6 m/s」「v₀」 |
| 高さ・長さ | 両矢印の細い線に数値。物の端から点線の補助線（「自然の長さ」「0.70 m」「l」） |
| 力 | 作用点から矢印（力の図では色つきの太い矢印、mg・kd などの記号） |
| 床・壁・天井 | 線と短い斜線。壁は灰色に塗ることもある |
| あらい面 | 区間を A・B で示し、線の下に「あらい水平面」 |
| 文字 | 数値と記号は欧文書体、記号は斜体（h, l, v） |

## このアプリの決まり

1. 図は中身に合わせて自動で切り詰める（`scene.js` の自動の外枠）。空白の大きな図にしない。
2. 場所は A・B の記号で示し、物体の左上に置く。問題文の終わりに「（図の A：投げた直後、B：いちばん高いところ）」と書く。棒グラフの見出しは場面の名前。
3. ばねはコイル。縮めた場面は輪を詰めて描く。
4. 動く場面には点線の道すじと矢じりを入れる（投げ上げは上がる点線、落下は下がる点線、振り子は円弧の点線）。
5. 速さの矢印は 0.6 mm の細さ、力の矢印は 0.9 mm で作用点に黒丸。
6. 高さ・長さは両矢印の直線＋点線の補助線（円弧は使わない）。
7. 文字どうし、文字と線が重ならない。基準面の文字は物体から離れた右端に置く。
8. 選ぶ問題の棒グラフには数値を出す。誤りの選択肢は、誤りが 1 つだけで、数値を見れば分かるものにし、解説も数値で書く。
