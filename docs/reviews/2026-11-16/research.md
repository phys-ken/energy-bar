# エネルギー棒グラフアプリの言葉遣いを直すための根拠集め

調べた日: 2026-11-16。リポジトリは編集していない。
凡例: 【確認】=一次資料の本文を実際に読んだ。【要約】=検索結果・二次記事の要約のみ。【経験則】=出典で確かめられず、調査担当の知識で書いた（採用前に先生が判断してください）。

---

## 1. 要点（このアプリの文に当てはめる規則、14個）

1. **問題文は必要最小限にする。** 教示文・本文・設問・図表の記述量を必要最小限にする（項目12）。設問部分だけで何を問われているかが分かるようにする（項目18）。
   出典: 石井ほか(2021)テスト問題作成ガイドライン【確認】[S1]。
   先生の指摘「問題文が2か所に分かれるのはだめ」の裏づけ。

2. **一文は短く、一文に言いたいことは1つ。** 公用文は「一文を短くする」「一文の論点は一つ」[S2]【確認】。やさしい日本語ガイドラインも同じで、一文に複数の内容があると理解が難しくなると書く [S3]【確認】。
   目安: 一文の平均30〜45字、読点は1文2個まで（yomiyasu 変換規則。個人開発ツールの目安で、公的基準ではない）[S9]【要約】。

3. **結論（問い）を先に、次に理由や条件。** 「結論は早めに示し、続けて理由や詳細を説明する」[S2]【確認】。ガイドライン項目17「問いたいこと・答え方を明確・簡潔に」[S1]【確認】。

4. **否定表現を避ける。使うなら強調する。** 設問で否定を使わない（項目19）。選択肢でも「〜でない」を使わない（項目29）。二重否定も「どうしても必要なとき以外は使わない」[S1][S2][S3]【確認】。
   注意: 項目19の「太字で強調」は否定語だけの話。問い全体を太字にする話ではない。先生の「問いを太字にしない」と矛盾しない。

5. **受身形・指示語・主語の省略をむやみに使わない。** 「受身形をむやみに使わない」「主語と述語の関係が分かるようにする」「指示語と指示される語は近くに置く」[S2]【確認】。受身は行動の主体が分かりにくくなる [S3]【確認】。
   先生の「仕事の主語は力」の方針とも整合する。

6. **余計な言い回しを削る。** 「回りくどい言い方や不要な繰り返しはしない」。例「問題があるということになる」→「問題がある」、「調査を実施した」→「調査した」[S3]【確認】。

7. **漢語より和語。** 「〜を実施する」「〜を抑制する」より「〜する」「抑える」。分かりやすさ・親しみやすさを高めるには述部に訓読みの動詞を使う（例: 進捗する→はかどる）[S2]【確認】[S3]【確認】。ただし物理の用語は用語のまま使い、日本語の部分だけ和語にする。

8. **用語を統一し、必要なら初出で説明する。** 専門用語は言い換えるか説明を付ける。同じ語は一貫して使う（括弧記号の用法も文書内で統一）[S2]【確認】。

9. **括弧・記号・強調を増やさない。** 公用文は「そのほかの括弧等はむやみに用いず、必要な場合は用法を統一して使用する」[S2]【確認】。AI文章の指摘でも、括弧による補足が主文を弱める、強調記号の偏りで重要度の差が消える、が挙がる [S8]【確認】。
   先生の「問題文中の括弧をやめる」「太字にしない」と同じ方向。

10. **感嘆符・絵文字・装飾を使わない。** 公用文では感嘆符は感動・強調を示す符号として扱われる [S2]【確認】。教材の画面では、先生の指摘（ガチャガチャする）の方針で不要。出典で「教材で感嘆符は不可」とまでは書かれていないので、これは方針としての判断。

11. **見れば分かることは書かない。** 冗長性効果: 同じ内容を画面上の文字と図で二重に示すと学習が妨げられうる。無関係な情報を削ると理解が深まる（一貫性の原則）[S5]【確認】。画面上の文字と図が離れていると視線の往復で負荷が増える（分割注意効果）ので、関連するものは近くに置く [S5]【確認】[S6]【要約】。
    注意: 冗長性の研究は「アニメ＋ナレーション＋同じ文字」が典型で、図＋短い文字が常に悪いわけではない。効果は条件で変わる [S6]【要約】。

12. **余計な選択肢・おふざけ・「上記のいずれでもない」を入れない。選択肢は長さ・構造を揃える。** 項目25・28・33・34 [S1]【確認】。

13. **フィードバックは「正誤だけ」で終えず、「何が・なぜ」を短く。** 詳しい説明は小分けにする。習熟度によっては正誤だけの方がよい場合もある。研究間で結果は一致しない [S7]【要約】（Shute 2008 の原文は未読）。
    語調は評価的でなく支援的に、が通説 [S7]【要約】。具体的な語彙（「ざんねん」等）についての日本語の研究は見つけられなかった。

14. **読み手の言語レベルに合わせる。** 項目11 [S1]【確認】。公用文は一般向けは「義務教育で学ぶ範囲の知識で理解できる」ことを求め、解説・広報では「です・ます」を基調とする [S2]【確認】。高1向けなので、中学で習わない漢語・略語は避けるか読みを添える。

### 補足（規則にしなかったが重要）
- 「禁止語リスト」だけでは直らない。別の曖昧な表現に置き換わるだけで文構造は変わらない。ルールを細かく与えすぎると不自然になる、という報告もある [S9]【要約】。語の置き換えより、主語・述語・条件を具体的に書き直す。
- 人間はAI文章を見分けられない（403名で人間文の正答率31.5%）[S10]【要約】。「AIっぽい」という感覚で直すより、上の読みやすさの規則で直す方が根拠が強い。

## 2. AIの日本語のクセ一覧

実測の裏づけの強さを付ける。
- 実測あり: 広島大学卒論(2026)・井本賢(2026)・財津ほか(2023)の測定 [S11]。いずれも小規模・未査読を含む。
- 指摘のみ: 記事に書かれているが数値の裏づけなし。
- 覆された: 実測では逆または裏づけなし。

### 教材・問題文に特有のクセ（出典は指摘が少なく、一部は経験則）

## 3. 物理の問題文の定型

### 確認できた実例の出典
2026年度大学入試問題 [S12]【確認】（実際に本文を抽出して読んだ）の力学・電気の冒頭と設問には、次の表現があった。
- 「地上の重力加速度の大きさを g とする。大気による抵抗は無視する。」
- 「地面を基準として鉛直上向きに y 軸を設定する。」
- 「質量 m の小球を、〜において位置 y＝y₀ から初速度ゼロで静かにはなした。」
- 「地面を重力による位置エネルギーの基準として、〜を求めよ。」
- 「〜を m、g、Y、e を用いて答えよ。」
- 「導線の抵抗と直流電源の内部抵抗は無視する。」
- 「〜は風の影響を無視できるものとする。」
- 「〜を求めよ。」「〜を答えよ。」「最も適切なものを選び記号で答えよ。」

他の出典で確認: 「なめらかな水平面上」「静かに放し」「空気の抵抗の影響を無視する」「重力加速度の大きさを g とする」が実際の問題・実験記述に使われている [S13]【要約】。

### 使ってよい表現
| 表現 | 備考 |
|---|---|
| 「重力加速度の大きさを g とする」 / 数値なら「9.8 m/s² とする」 | 「大きさ」を付けるのが定型 [S12]【確認】 |
| 「空気抵抗は無視する」「摩擦は無視する」 | 「大気による抵抗」「空気の抵抗の影響を無視する」も使われる [S12][S13] |
| 「なめらかな〜」（摩擦なし） | 「なめらかな水平面」。表記は仮名が多い [S13]【要約】。漢字「滑らか」も使われるが一貫させる |
| 「静かに放す」「初速度ゼロで静かにはなす」 | 初速度0を表す定型 [S12]【確認】。簡潔にするなら「静かに放す」 |
| 「〜を基準とする」「〜を重力による位置エネルギーの基準とする」 | 高さの基準を示す [S12]【確認】。「基準面」は教科書的 [S14]【要約】 |
| 「〜を求めよ」「〜を答えよ」「〜を選べ」 | 入試・教科書とも定型。敬体の「〜を求めましょう」より設問らしい。ただし生徒向けアプリでは「〜か。」「〜はいくらか。」の方が自然な場合もある（経験則）【経験則】 |
| 「〜を m、g、h を用いて表せ」 | 使ってよい文字を明示する定型 [S12]【確認】 |
| 「物体」「小球」「台車」など、図に合わせた名称 | 図の通りの語に統一する |

### 避ける表現
| 避ける | 理由・代わり |
|---|---|
| 「〜を系とする」を生徒向けの文に無条件に使う | 検索では問題文での典型例が確認できなかった。教科書・用語の説明では使われるが、高1向けには「物体と地球」と具体的に書く方が分かりやすい（先生の方針「系は物体と地球」と整合）【経験則】 |
| 「重力場」 | 先生の方針。「物体と地球」 |
| 「できるだけ」「適当な」「ある程度」 | 曖昧。条件は値・語で固定する [S3]【確認】（曖昧な表現はできる限り使わない） |
| 「〜でないのはどれか」 | 否定表現 [S1]【確認】。必要なら強調。可能なら肯定の問いに |
| 問題文の末尾に「〜しましょう」「〜してみよう」 | 設問の型から外れる。AIくさい。「〜せよ」「〜を選べ」か、疑問文 |
| 「大きい」「小さい」だけで比較対象がない | 何と比べるか書く |
| 「ただし〜」を設問の後ろに付ける | 条件は前に（項目18）[S1]【確認】 |

### 注意
- 上の「定型」は大学入試・教材の実例で確認したが、「どの言い方が高校1年に最も自然か」を比べた研究は見つからなかった。最終的には先生が使っている教科書・問題集の語に揃えるのが安全。
- アプリが敬体（です・ます）の画面か、常体の問題文かは、公用文では「解説・広報等は『です・ます』を基調」[S2]【確認】。問題文は常体の「〜せよ」が一般的。1つの画面で敬体と常体を混ぜない（公用文「一つの文・文書内では統一」[S2]【確認】）。
