# 場面の図の全数調査（2026-11-16）

`node samples/scenes.js` が、生成器のすべての場面を、分かれ道（止まる／通りぬける、途中／いちばん高い所、初速あり／なし、数値のちがいで図が変わるもの）ごとに 1 枚ずつ描く（`samples/out/audit/`、一覧は `list.tsv`）。
50 枚を `docs/figure-style.md` の決まりで 1 枚ずつ見た。S_ は棒グラフの問題（読む・かく・選ぶ）、C_ は計算の問題。

## 1 回目（描き直す前）に見つけたこと → 部品から直した

- 図が大きな空白の中に小さく描かれていた（投げ上げの図など）→ 中身に合わせて自動で切り詰める
- 終わりの場面の物体を灰色の点線にしていた → どの場面も実線、A・B の記号
- 図の中に場面の名前（「途中」「投げた直後」）を書いていた → A・B の記号、問題文の終わりで「図の A：投げた直後、B：上っている途中」
- ばねがギザギザ → コイル
- 動きが分からない → 投げ上げ・落下・振り子に点線の道すじ、動いている物体に速さの矢印
- 「基準面（投げた位置）」の文字が物体の名前と重なる → 文字は「基準面」だけ、物体から離れた所へ

## 3 回目（動きの線・v = 0・道すじを足した後、51 枚）

- 動いている物体すべてに「≡」、止まった物体に「v = 0」、斜面の場面に道すじの点線が入ったことを 1 枚ずつ確かめた。
- 見つけて直したこと: 「v = 0」が記号 B と重なる（物体の右へ）／左へ動いて止まる場面で「v = 0」がばねに重なる（物体の真上へ）／
  投げ上げの途中の B の「≡」が A の速さの矢印と重なる（途中の位置を高く）／押す場面の A の「≡」が「押す力」の文字と重なる（押す場面の A には付けない）／
  ばね→斜面で道すじの点線が「基準面」の文字を通る（文字を床の線の下へ）。
