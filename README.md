# energy-bar

物理基礎「力学的エネルギー」のエネルギー棒グラフ教材（演習アプリ・シミュレーション）。静的ページで、GitHub Pages から配信する。

- 棒グラフはエネルギー（ストック）だけを棒にし、仕事（フロー）は「まえ」と「あと」の間の矢印で表す。
- `index.html` … 試作（計算用紙・電卓・問題の型の動作確認）。`proto/scratch.html` と同じもの。
- 自己テスト: `google-chrome --headless=new --dump-dom "file://$PWD/index.html?test"` のタイトルが `TEST ALL OK`。
